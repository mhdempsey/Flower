# Flower Icons

Place your 4 flower images in this folder with these exact names:

- `flower1.png` - First flower image
- `flower2.png` - Second flower image
- `flower3.png` - Third flower image
- `flower4.png` - Fourth flower image

The extension will randomly select one of these flowers to display as a small icon at the bottom center of the new tab page.

## Image Requirements

- Format: PNG (with transparent or solid background)
- Size: Recommended 200-400px width
- Style: Blue flowers on cream/yellow background (as provided)
- Names must match exactly (flower1.png through flower4.png)

## Installation

1. Save your 4 flower images with the names above
2. Place them in this folder (`florilege/extension/images/flowers/`)
3. Reload the extension in Chrome
4. The random flower will appear automatically on new tabs
